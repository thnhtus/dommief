# Cấu hình đa ngôn ngữ

Dommief hỗ trợ **hai chế độ** i18n (không được trộn):

## Base mode (khuyên dùng)

Mỗi locale là prefix path riêng:

```ts
locales: [
  { id: 'en-US', name: 'English' },
  { id: 'vi-VN', name: 'Tiếng Việt', base: '/vi-VN/' },
];
```

Route:

| locale | file | URL |
|---|---|---|
| en-US | `guide/getStarted.md` | `/guide/get-started` |
| vi-VN | `guide/getStarted.vi-VN.md` | `/vi-VN/guide/get-started` |

## Suffix mode

Bản mặc định không hậu tố; locale khác thêm `.vi-VN`:

```ts
locales: [
  { id: 'en-US', name: 'English', suffix: '' },
  { id: 'vi-VN', name: 'Tiếng Việt', suffix: '.vi-VN' },
];
```

Route:

| locale | file | URL |
|---|---|---|
| en-US | `guide/getStarted.md` | `/guide/get-started` |
| vi-VN | `guide/getStarted.vi-VN.md` | `/guide/get-started.vi-VN` |
| vi-VN | `index.vi-VN.md` | `/.vi-VN` |

## File dịch

`<tên>.<localeId>.md` cạnh file gốc (`getStarted.vi-VN.md` cạnh `getStarted.md`).

## hreflang & sitemap

**Bắt buộc** `sitemap: { hostname: 'https://...' }` để có hreflang trong HTML và xhtml:link trong sitemap.

Thiếu hostname → cảnh báo, bỏ hreflang/xhtml.

## Language switcher

Navbar dropdown tự động (slot `LangSwitch`). Link sang bản dịch nếu có; không có → về trang chủ locale; chưa có trang chủ → không hiện (tránh 404). Override `.dommief/theme/slots/LangSwitch.tsx`.

## Service strings

Merge: `default/locales/<id>.json` < theme package < `.dommief/theme/locales/<id>.json`. Thiếu key rơi về `en-US`.

Key phổ biến: `search.placeholder`, `search.count`, `skipToContent`, `colorSwitch.auto|toLight|toDark`, `locale.switch`.

## Parity

```ts
i18n: { requireParity: true, allowSingleLocale: ['/reference/**'] }
```

- `requireParity: false` (mặc định): warning gom nhóm.
- `requireParity: true`: throw `i18n_parity` (exit ≠ 0).
- `allowSingleLocale`: key 1 locale cố ý (pattern có '/' đầu).

Trang thiếu bản dịch → không route, không fallback.
