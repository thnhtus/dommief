# Cấu hình đa ngôn ngữ

Dommief hỗ trợ **hai chế độ** i18n (không được trộn trong cùng config):

## Base mode (khuyên dùng)

Mỗi locale là một prefix path riêng. Bản mặc định (`suffix: ''`) không có prefix:

```ts
// dommief.config.ts
export default {
  title: 'My Docs',
  locales: [
    { id: 'en-US', name: 'English' },           // base '/', suffix ''
    { id: 'vi-VN', name: 'Tiếng Việt', base: '/vi-VN/' },
    { id: 'fr-FR', name: 'Français', base: '/fr-FR/' },
  ],
};
```

Route ví dụ:

| locale | page | URL |
|---|---|---|
| en-US | `guide/getStarted.md` | `/guide/get-started` |
| vi-VN | `guide/getStarted.vi-VN.md` | `/vi-VN/guide/get-started` |
| vi-VN | `index.vi-VN.md` | `/vi-VN/` |

## Suffix mode

Bản mặc định không có hậu tố; các locale khác thêm hậu tố `.<localeId>` vào slug file:

```ts
locales: [
  { id: 'en-US', name: 'English', suffix: '' },
  { id: 'vi-VN', name: 'Tiếng Việt', suffix: '.vi-VN' },
];
```

Route ví dụ:

| locale | file | URL |
|---|---|---|
| en-US | `guide/getStarted.md` | `/guide/get-started` |
| vi-VN | `guide/getStarted.vi-VN.md` | `/guide/get-started.vi-VN` |
| vi-VN | `index.vi-VN.md` | `/.vi-VN` |

> **Lưu ý:** trang chủ vi-VN trong suffix mode là `/.vi-VN` (thư mục ẩn `.vi-VN/` trong `dist/`) — preview/production server phục vụ bình thường.

## Quy tắc file dịch

Đặt file dịch cạnh file gốc với hậu tố `.<localeId>`: `getStarted.vi-VN.md` cạnh `getStarted.md`. File không có hậu tố = bản mặc định (en-US).

## hreflang & sitemap (yêu cầu)

Để có `<link rel="alternate" hreflang="…">` và `<xhtml:link>` trong `sitemap.xml`, **bắt buộc** khai báo `sitemap.hostname` (URL tuyệt đối):

```ts
sitemap: { hostname: 'https://docs.example.com' },
```

Nếu thiếu hostname:
- hreflang trong HTML bị bỏ qua (cảnh báo 1 lần).
- sitemap chỉ có `<loc>` (không có xhtml:link), giống site 1 locale.

## Language switcher

Navbar tự động hiển thị dropdown chuyển locale (slot `LangSwitch`). Quy tắc:
- Nếu trang hiện tại có bản dịch (`route.alternates[localeId]`) → link tới bản dịch đó.
- Không có bản dịch → link về trang chủ locale (`base` hoặc `suffix`).
- Nếu trang chủ locale chưa tồn tại (chưa có `index.<id>.md`) → locale đó **không render** trong switcher (tránh link chết 404).
- Site 1 locale: switcher không render.

Override slot: `.dommief/theme/slots/LangSwitch.tsx`.

## Service strings (theme locales)

Theme mặc định ship `locales/en-US.json` và `locales/vi-VN.json` (key phẳng: `search.placeholder`, `search.count`, `skipToContent`, `colorSwitch.*`, `locale.switch`).

Merge ưu tiên (thấp → cao):
1. `dommief-theme-default/locales/<id>.json`
2. theme package đang dùng (`config.theme`)
3. `.dommief/theme/locales/<id>.json` (local override thắng mọi thứ)

Thiếu key ở một locale → rơi về `en-US`, **không** hiển thị key thô.

## Parity check (cảnh báo/ép buộc)

```ts
i18n: {
  requireParity: true,
  allowSingleLocale: ['/reference/**'],
},
```

- `requireParity: false` (mặc định): build cảnh báo gom nhóm: `Missing translations for N keys: key1 (vi-VN); key2 (fr-FR)…`
- `requireParity: true`: build **throw** `DommiefError` code `i18n_parity` (exit code ≠ 0).
- `allowSingleLocale`: key chỉ tồn tại ở 1 locale (ví dụ API reference chỉ en-US) được bỏ qua nếu khớp pattern. Pattern khớp trên path có '/' đầu (`reference/**` = `/reference/**`). Mặc định `[]`.

Trang thiếu bản dịch: **không tạo route**, không fallback nội dung.
